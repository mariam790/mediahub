
MediaHub est une plateforme web destinée à la **gestion et à la diffusion de contenus multimédias**. Le projet sera développé progressivement avec Laravel afin de mettre en pratique les différentes fonctionnalités d’un framework côté serveur.

Au cours des différentes semaines, la plateforme intégrera notamment le **routage, les vues, la base de données, l’authentification, la gestion des médias et une API REST**. L’objectif de la première semaine est de mettre en place le squelette initial du projet Laravel, de le configurer et de le versionner avec Git.
